# OpenSRE Demo - Catalog API

## Overview

OpenSRE Demo is an AI-powered Site Reliability Engineering (SRE) platform that demonstrates how observability, Kubernetes, and Large Language Models (LLMs) can work together to assist in incident detection and root cause analysis.

This project consists of:

- Catalog API (Python)
- OpenSRE Backend (FastAPI)
- React Dashboard
- Kubernetes (Kind)
- VictoriaMetrics
- Loki
- OpenTelemetry
- AI Assistant
